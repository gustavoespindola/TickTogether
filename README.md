# TickTogether
TickTogether is a Chrome extension that replaces the default new tab page with a customizable dashboard displaying multiple user-selected time zones. This feature is designed to assist globally distributed teams in coordinating across different time zones by providing a clear and personalized view of selected clocks.

This aligns with Chrome Web Store's single-purpose policy, as the extension focuses solely on enhancing the new tab page to display time zone information, without introducing unrelated functionalities.


## Requested Permission: storage

Justification: The storage permission is utilized to save user preferences locally, such as selected time zones and custom labels. This ensures that the user's configuration persists across browser sessions, providing a consistent and personalized experience. The extension does not access, collect, or transmit any personal or sensitive user data.

## Privacy Policy
